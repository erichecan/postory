# PoStory Ads Studio 视觉规范

本界面沿用 PoStory Design System v1 的品牌色、字体角色、4 px 网格与圆角体系，并为高密度广告运营工作区定义独立布局。它是 Ads Studio 的一致视觉基线，后续真实产品实现应把这些语义值接入主项目设计 token。

## 视觉方向

清晰、克制的运营台：品牌色只强调关键行动，浅灰蓝画布承载分区，绿/橙/红只表达状态。运营控制台采用高密度布局；客户入口减少操作和指标密度，保留品牌与清晰的审批/报告信息。

演示场景统一为爱尔兰本地商家：金额用 EUR，门店时间按 Europe/Dublin 展示；商家看到“预约、优惠券核销、到店销售”等经营语言。广告平台结构仅作为次级信息。流程卡片使用文字标签区分“客户确认 / 运营建立 / 系统自动 / 异常审批”，不单靠颜色表达责任归属。

## 组件与交互

- 页面标题 24 px / 700；面板标题 16 px / 700；正文 14 px；说明和状态 12 px。
- 主操作高度至少 44 px；表单控件高度 44 px；可聚焦操作有可见焦点环。
- 状态用文字与颜色共同表达，不仅依靠色彩。审批、授权、超预算均有说明。
- 表格行 hover、主按钮 hover、下拉菜单、弹窗、步骤进度、状态标签沿用同一描边与间距。
- 客户入口使用同一品牌、卡片和状态色，但隐藏内部导航、跨客户选择和操作审计。
- 所有会改变演示状态的按钮给出即时反馈。浏览器刷新后保留演示状态，重置操作可恢复默认。

## 响应式

桌面显示侧栏与主内容；窄屏将侧栏折叠为横向滚动导航，统计卡片改成两列，表格可横向滚动，弹窗占满屏宽且保留明确关闭操作。界面不依赖固定高度裁切内容。
