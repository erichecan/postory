# PoStory Design System v1

本轮目标：全站一致、清楚、可维护。用户已明确将一致性优先于原来的逐像素参考图还原；旧参考稿继续作为品牌和内容来源，不再控制每页独立字号和固定高度。

在线规范页：`/demo/design-system`。正式营销页面及客户工作区已采用本规范；登录/注册/找回密码以及价格、法律、日历预览和旧客户工具共用颜色、字体角色、控件和客户页头。模板、帖子及编辑器画布里的作品文字保持自身字体，它们属于内容素材，不属于应用 UI。

## 文件与职责

- `src/components/design-system/tokens.css`：唯一的颜色、字号、间距、容器、圆角和阴影变量。
- `src/components/design-system/components.css`：语义字体层级、共用控件、各组件密度及统一响应式规则。
- `src/components/visual/visual.css`：页面布局与图片编排，已移除 553 处字号、字重、行高等旧声明；不允许在此添加字体覆盖。
- `src/components/visual/primitives.tsx`：共用 CTA、标签、区块标题、图片、平台标识和检查列表。
- `src/components/visual/shell.tsx`：共用公开页和客户页导航、账号菜单、手机菜单及页脚。
- `src/app/demo/design-system/page.tsx`：真实组件样例，展示默认、禁用、错误及焦点状态。

## 字体角色

Inter 为英文 UI 字体，Noto Sans SC 为中文回退。字重限定为 400（正文）、500（标签）、600（操作/卡片）和 700（标题）。采用离散断点，不再随每页宽度单独缩放。

| 角色 | 桌面 | 中间尺寸 | 手机 ≤700 px | 行高 / 字重 |
|---|---:|---:|---:|---|
| 营销 H1 | 48 px | ≤900 px：40 px | 36 px | 1.12 / 700 |
| 工作区、认证、旧工具页面 H1 | 32 px | 32 px | 28 px | 1.2 / 700 |
| 营销区块 H2 | 32 px | 32 px | 28 px | 1.2 / 700 |
| 活动主卡片标题 / 对话框标题 | 24 px | 24 px | 24 px | 1.25 / 700 |
| 工作区面板 H2 | 20 px | 20 px | 20 px | 1.3 / 700 |
| 营销卡片标题 H3 | 18 px | 18 px | 18 px | 1.35 / 700 |
| 紧凑卡片、步骤、工作区 H3 | 16 px | 16 px | 16 px | 1.4 / 700 |
| Hero 引导文案 | 18 px | 18 px | 16 px | 1.6 / 400 |
| 营销正文、输入内容 | 16 px | 16 px | 16 px | 1.6 / 400 |
| 工作区正文、卡片说明、操作 | 14 px | 14 px | 14 px | 1.4–1.6 / 400–600 |
| 辅助信息、状态、日期、预览文案 | 12 px | 12 px | 12 px | 1.4–1.5 / 400–600 |

48 / 40 / 36 的变化来自所有公开页共享的断点。32 / 20 的工作区层级属于工作区密度，不能按单页自行改变。用户阅读的 UI 文案不再使用旧稿中的 6–11 px 字号；平台标志等图形字符不算正文。

## 间距、容器与组件

- 4 px 基础网格。常用值：4、8、12、16、24、32、40、48、64 px。
- 营销内容最大宽度 1200 px；工作区最大宽度 1280 px。桌面边距 32 px，手机 16 px。
- 营销区块上下间距：桌面 64 px、中间尺寸 48 px、手机 40 px。
- 主要卡片间距 24 px，紧凑数据/内容卡片 16 px，手机紧凑网格 12–16 px。
- 按钮/图片圆角 8 px，卡片 12 px，大型面板/对话框 16 px；照片和帖子预览按相应组件取值。
- 主/次 CTA：字号 14 px、字重 600、最小高度 48 px；导航 CTA 最小高度 44 px。手机导航 CTA 可采用 12 px 紧凑文案，但保持 44 px 点击高度。
- 输入/选择/文本域：字号 16 px、最小高度 48 px、统一边框、内边距和错误状态。
- 桌面 Logo 显示宽度 180 px，按原图比例显示，高度约 48 px；手机页头紧凑规格 108 px。采用独立裁切素材，不使用 transform 二次缩放。
- 页面顶部导航高度：桌面/平板 72 px、手机 64 px。≤1199 px 折叠菜单；支持 Escape 和焦点返回。
- 公共操作图标 16 px，图标圆盘里的图标 24 px。社媒标志按所在组件尺寸显示。
- 区块和卡片采用自然文档高度。较长标题和文案自动换行，不以固定高度裁切或用绝对定位把 CTA 压在正文上。
- 公共网站统一导航顺序、评估按钮和页脚；工作区采用 Dashboard / My Campaign / Marketing Calendar / My Brand。
- 工作区旧工具复用相同客户页头和身份菜单，原语言切换仍保留。管理员页面保留业务导航，基础颜色和表单规格同步。

## 响应式规则

四列内容示例依次降为三列、两列。步骤和周计划降列；公开 Hero 在 ≤900 px 堆叠；手机保持文案、操作、主视觉的顺序。工作区在中间尺寸将侧面板移到主内容下方；手机日历使用月份列表。标题断点来自全局 token，布局断点来自统一组件规则，不使用参考图宽度做字体缩放。

## 后续修改规则

1. 新页面先选择语义角色；使用 `SectionTitle`、`CTA`、共用导航等现有组件。
2. 改某类字号或颜色时改 token/组件，不追加 `.ps-home h2` 一类页面例外。
3. 修改布局时只调整容器、网格、间距和图片，不改正文密度以硬塞内容。
4. 同一角色在不同页面必须一致；特殊角色需先在本规范和组件页中定义。
5. 使用浏览器检查实际样式和截图；同时验证长文案、手机、中间尺寸及键盘操作。
