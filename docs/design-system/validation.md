# Design System v1 验收记录

日期：2026-10-06。验收目标为全站视觉一致性；参考稿继续提供品牌、图片和内容，不再逐页追求像素匹配。

## 已实施

统一字体角色、颜色、4 px 间距网格、容器、圆角、按钮、表单、状态标签、导航和响应式断点。营销页、客户工作区、认证页、价格、法律、日历预览及旧客户工具接入共用规范。新下载的 Logo 继续使用原素材。

营销主标题为 48 / 40 / 36 px，工作区主标题为 32 / 28 px；正文为 16 px，紧凑工作区正文为 14 px，辅助文字为 12 px。区别来自语义角色与统一断点，不再由每页独立覆盖字号。

修正了活动卡片文字与按钮重叠、中间尺寸作品拼图溢出、窄屏语言切换挤出导航等问题。语言切换在窄屏菜单内保留。

## 浏览器验证

以下检查均通过；已验证页面未发现横向溢出、图片加载失败或浏览器运行错误。

- 15 个主要页面：桌面 1440 × 900；响应式 375 × 812、390 × 844、768 × 1024、1280 × 800、1440 × 900，共 90 项页面与视口检查。
- 15 个主要页面在 1440 / 768 / 390 px 下，共 45 项实际标题字号、字重、导航高度和 CTA 规格检查。
- 组件规范、登录、注册、找回密码、价格、法律、日历预览及 5 个旧客户工具，1440 × 900 和 390 × 900，共 24 项检查。
- 10 组交互检查：作品筛选与对话框焦点、日历月份、表单验证、活动标签与详情、反馈预览、日历筛选、品牌编辑预览、移动导航、登录保护、真实客户数据与所有权边界。

截图和 JSON 结果位于 [截图总览](../../preview/design-system/index.html)。主要页面检查包含 HTTP 状态、运行错误、图片加载和横向溢出。客户身份验证使用只读访问；演示保存只验证本地预览，表单验证未发送真实邮件。

## 代码检查

`npm run typecheck`、`npm run lint`、`npm run build` 完成。lint 有 6 条现有未使用变量警告，无错误。页面布局 CSS 中已清除 553 处旧字体声明，并以持久校验脚本防止恢复独立字号覆盖。

## 验收边界

本轮主动调整了参考稿中不一致的字体、间距、按钮及布局高度，因此与旧稿有视觉差异。图片沿用现有素材，原图分辨率和裁切质量未重新制作。帖子、模板和编辑器作品中的字体属于内容设计，不受应用 UI 字体层级限制。

管理员业务导航保留，基础颜色和表单随全局规范更新；本轮没有逐项验收管理员业务流程或编辑器画布的全部状态。真实邮件发送和外部发布不属于本轮验证。
