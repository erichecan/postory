# 开发踩坑记录(持续更新)

记这份文档的目的:这些坑一旦踩过、修好了,不该在下一个开发周期/下一次会话里重新踩一遍。新开一个周期前建议扫一眼。

## 1. Next.js 16:`middleware.ts` 已废弃,改名 `proxy.ts`

导出函数名 `proxy`(或默认导出),写法跟原来的 middleware 完全一样,只是文件名和函数名变了。本项目文件在 `src/proxy.ts`。

官方明确强调:**鉴权不能只靠 proxy/middleware 一层**,因为 Server Action 可以被直接 POST 调用,不一定经过 proxy 的 matcher。所以每个 Server Action 内部都要再调一次 `requireSession()` 自证(见 `src/lib/auth.ts`)。

## 2. Prisma 7:datasource url 挪到了 prisma.config.ts

- `schema.prisma` 的 `datasource` 块里**不能再写** `url = env("DATABASE_URL")`,只留 `provider`
- 连接串配置挪到项目根目录的 `prisma.config.ts`,用 `defineConfig({ datasource: { url: env('DATABASE_URL') } })`
- `PrismaClient` 运行时也要求传 `adapter`(本项目用 `@prisma/adapter-pg` + `pg`),否则报错要求驱动适配器,不能直接 `new PrismaClient()`

## 3. `npm install prisma@latest` 会装到 8.0 的 RC 版本

`prisma@latest` 目前指向 `8.0.0-rc.x`,是完全重构过的"Prisma Developer Platform"CLI(`migrate` 命令都没了,变成 `migration`/`contract`/`deploy` 等一套新命令,围绕 Prisma 自己的云平台设计)。**本项目锁定在 `7.10.0` 稳定版**,`package.json` 里已经固定版本号,不要因为"更新一下依赖"顺手升级 prisma 包。

## 4. Prisma CLI 不会自动读 `.env.local`

Next.js 运行时会自动读 `.env.local`,但 Prisma CLI(`prisma migrate` / `prisma db seed` 等命令)是独立进程,默认只找 `.env`。`prisma.config.ts` 里已经用 `dotenv` 显式加载了 `.env.local` 再加载 `.env`。新增环境变量后,记得跑一次 `npx prisma migrate status` 确认 Prisma 这边也真的读到了,不要只测 Next.js 那一侧。

## 5. `body { flex flex-col }` + 子元素 `mx-auto max-w-*` 会让中文内容"塌缩成竖排"

**现象**:页面渲染出来,中文标题一个字一行,像竖着写的诗,卡片宽度只有几十像素。

**根因**:项目根布局 `src/app/layout.tsx` 里 `<body className="min-h-full flex flex-col">`,body 是纵向 flex 容器。子元素只写 `mx-auto max-w-5xl`(没有显式宽度)时,`mx-auto` 的 auto margin 会**取消** flex 的 stretch 拉伸行为,子元素退化成"shrink-to-fit"(缩到刚好包住内容的宽度)。中文文本没有空格,浏览器可以在任意两个汉字之间断行,所以"最小内容宽度"只有一个字——整条链路(main → grid → card → 文字)全部跟着塌缩到这个最小宽度。

**修法**:任何要在这个 flex 布局下居中的容器,必须同时写 `w-full` 和 `max-w-*`,不能只写 `mx-auto max-w-*`:

```tsx
// ❌ 错误,会塌缩
<main className="mx-auto max-w-5xl p-8">

// ✅ 正确
<main className="mx-auto w-full max-w-5xl p-8">
```

`/admin`、`/dashboard` 两个页面已经这样修过。**新页面照抄这个类名组合,别再踩一次。**

## 6. 这版 shadcn 的 Button 不支持 `asChild`,底层是 Base UI 不是 Radix

`src/components/ui/button.tsx` 用的是 `@base-ui/react/button`(Base UI),不是常见的 Radix UI + `asChild` 那一套,`<Button asChild><Link>...</Link></Button>` 这种写法会直接类型报错。

**要把 Button 做成链接,用 `buttonVariants` 直接套类名**,不要用 `asChild`:

```tsx
import Link from 'next/link'
import { buttonVariants } from '@/components/ui/button'

<Link href="/somewhere" className={buttonVariants({ variant: 'outline' })}>
  文字
</Link>
```

## 7. 表单里别手写原生 `<select>`,跟 Base UI 的 `Input` 混用会报 Console Error

同一个 `<form>` 里如果既有 shadcn 的 `Input`(Base UI 组件)又有手写的原生 `<select>`,浏览器 Console 会报:
"Base UI: A component is changing the default value state of an uncontrolled FieldControl after being initialized."

不影响功能(表单照样能提交、能保存),但控制台会一直有个 Issue 角标。**统一用 `npx shadcn@latest add select` 装的 Select 组件**(`@/components/ui/select`),组合方式:

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select'

<Select name="status" defaultValue={currentStatus}>
  <SelectTrigger><SelectValue /></SelectTrigger>
  <SelectContent>
    <SelectItem value="ACTIVE">正常</SelectItem>
    <SelectItem value="SUSPENDED">暂停</SelectItem>
  </SelectContent>
</Select>
```

`name` 属性会自动在表单提交时带上选中的 value,不用额外写 hidden input。已在 `src/components/client-limit-form.tsx` 改过来。

## 8. Select 用受控 `value`(不是 `defaultValue`)时,`<SelectValue />` 不会自动显示选项的中文 label

**现象**:`<Select value={type} onValueChange={...}>` 配合 `<SelectValue />`(不传 children),触发器上显示的是原始 value(比如 `"text"`),不是对应 `SelectItem` 里写的中文文案(比如"商家手填")。这跟第 7 条不受控 + `defaultValue` 的写法表现不一样——那种情况下 `<SelectValue />` 能正确显示 label,受控模式下就不行了。

**根因**:Base UI 的 `<Select.Value>` 只有在 item 的 `value` 是 `{ value, label }` 形状的对象时,才会自动帮你从 label 字段取显示文案;`value` 是纯字符串(比如 `SelectItem value="text"`)时,它没法反查出对应哪个 `SelectItem` 的 children 文本,只能显示原始字符串。

**修法**:给 `<SelectValue>` 传一个 render function,自己维护一份 `value -> 中文 label` 的映射:

```tsx
const FIELD_TYPE_LABELS: Record<TemplateFieldType, string> = {
  text: '商家手填',
  image: '图片',
  ai_generated: 'AI 生成',
}

<SelectTrigger>
  <SelectValue>{(value: TemplateFieldType) => FIELD_TYPE_LABELS[value]}</SelectValue>
</SelectTrigger>
```

`src/components/new-template-form.tsx` 里的字段类型选择器已经这样修。**以后任何"受控 Select + 字符串 value"的场景照抄这个写法**,不要假设 `<SelectValue />` 空写法在受控模式下也能自动显示 label。
