# 代理商合作销售 — 需求原话存档

## 一、用户粘贴的改造计划原文（2026-10-18）

PoStory 合作销售页面与流程改造计划

一、统一业务规则

- 代理商负责销售、客户沟通和维护；PoStory 负责内容生产及约定的发布执行。
- 合作按客户、平台和产出规模打包预付费，代理商自行决定对外售价。
- 同一张图片适配不同平台，算一份内容，不重复扣图片额度。生成不同图片才扣额度。
- 平台费用对应平台适配、账号管理及约定的发布执行，与图片额度分别显示。
- 免费试做提供 3 张图片。试做名额的适用范围需要在上线前确定，建议每位新合作方选择一个客户体验一次。
- 视频的计数、修改是否扣额度等尚未确定，不直接套用图片规则。
- 内部生产过程由 PoStory 管理。对外提供资料提交、内容查看、必要确认和交付汇总。

二、合作介绍页面设计与生产计划

目标：让营销个人或代理商迅速理解合作方式，并愿意提交一个真实客户试做。

建议设置独立的合作介绍页，主按钮统一为"免费试做 3 张图片"，次按钮为"查看合作流程"。

页面结构：

| 页面部分 | 展示内容 | 需要生产的材料 |
|---|---|---|
| 首屏 | "你负责客户，我们负责内容生产与执行。"说明预付费、自主定价和免费试做 | 首屏文案、一组真实制作的内容样例 |
| 适合谁 | 服务本地商家的营销个人、代理商，以及需要外包内容生产的团队 | 三类简短合作场景 |
| 合作分工 | 代理商维护客户；客户提供事实和素材；PoStory 完成约定交付 | 简洁分工图 |
| 能交付什么 | 图片、短视频、30 天营销计划、平台适配及约定的发布服务、月报 | 内容展示卡、视频样例、月报预览 |
| 如何合作 | 提交资料 → 查看计划和样片 → 确认方案并预付费 → 持续提交与交付 | 与真实界面一致的流程截图 |
| 计费说明 | 按客户和服务范围报价；同图跨平台不重复扣图片额度；代理商自主定价 | 一个直观的额度示例 |
| 客户如何参与 | 代理商转发专属链接，客户补资料、上传素材、绑定账号 | 客户提交页预览 |
| 常见问题 | 试做范围、素材要求、交付时间、修改、平台绑定、续费 | FAQ 文案 |
| 结束引导 | 提交一个客户，开始免费试做 | 试做入口、直接联系方式 |

额度示例应明确展示："3 张不同图片，各适配 Instagram 和 Facebook，共 6 个平台版本，使用 3 张图片额度。"

生产步骤：

1. 完成合作定位、分工、计费口径和 FAQ 文案。
2. 选定一个虚构样板门店，制作完整品牌资料、3 张样片、跨平台版本、一条视频样例和一份月报样本。
3. 完成页面布局，优先适配手机访问和消息转发。
4. 接入试做入口和流程演示，并补齐链接分享时显示的标题、摘要和封面。
5. 核对全站相关说法，确保合作页、试做页与实际交付规则一致。

完成标准：访客能在短时间内看懂合作分工、采购方式、图片计数规则，以及如何开始试做。

三、流程演示改造计划

目标：演示代理商和客户真实参与的过程，让合作方看懂自己需要做什么、最终会收到什么。

建议用一个独立演示入口，沿用同一个样板门店的数据。现有共用演示账号不再作为主要销售入口。

| 演示步骤 | 页面内容 | 需要改造的部分 |
|---|---|---|
| 1. 提交客户资料 | 品牌、行业、地区、目标、平台、图片素材 | 用预填样例展示提交界面 |
| 2. 查看 30 天计划 | 每条内容的主题、形式、目标平台、建议日期 | 从现有日历中整理出完整、连贯的月度计划 |
| 3. 查看试做样片 | 3 张不同图片、配套文案、各平台适配版本 | 按"原始内容"归组，避免将适配版本显示为新增额度 |
| 4. 确认交付方案 | 客户、平台、内容额度、交付周期及预付款状态 | 展示服务确认页面；演示中不触发真实付款 |
| 5. 转发客户入口 | 客户补素材、提交活动、绑定社交账号 | 展示代理商转发和客户填写两种视角 |
| 6. 查看交付汇总 | 管理客户数、各客户平台、产出数量、交付状态、月报 | 提供简洁的代理商汇总视图 |

演示数据要求：

- 品牌名称、行业、素材、营销计划和月报使用同一套信息。
- 内容状态完整覆盖待确认、已确认、待发布和已发布示例。
- 图片额度按不同图片统计；平台版本和发布次数单独统计。
- 所有样例清楚标注为演示数据，模拟发布和模拟表现数据不得冒充实际成果。
- 社交账号绑定展示示例状态，不要求演示访客授权自己的账号。
- 演示浏览不修改公共样例；需要真实试做时，进入独立试做流程。

生产步骤：

1. 整理一套完整样板数据，替换当前不一致或缺图的演示内容。
2. 完成提交、计划、样片、客户入口和交付汇总页面。
3. 增加明确的步骤导航，让访客能顺着流程看完。
4. 在各阶段设置"用自己的客户免费试做"入口。
5. 录制一段简短演示视频，供代理商通过消息直接转发。

完成标准：合作方无需接触内部生产工具，即可看懂从资料收集到月度交付的全过程。

四、免费试做改造计划

目标：让合作方用一个真实客户验证质量，试做资料能够直接延续到付费服务。

建议将免费试做做成独立入口，与普通终端客户的咨询评估表区分开。

第一步：提交资料

| 信息 | 首次提交要求 |
|---|---|
| 合作方姓名和联系方式 | 必填，至少留一种可回访方式 |
| 客户品牌、行业、地区 | 必填 |
| 产品、服务或本次活动 | 必填 |
| 目标受众、希望突出什么 | 简短填写 |
| 希望适配的平台 | 选择 |
| Logo、照片、参考内容 | 上传；缺少素材时说明可采用的制作方式 |
| 官网或现有社交账号 | 选填 |
| 语言与风格偏好 | 选择或补充 |

首次试做不要求绑定社交账号；客户进入实际发布服务时，再通过对应客户入口完成授权。

第二步：确认提交

- 显示资料是否完整、预计交付时间和试做范围。
- 提供专属查看链接，允许补充资料、查看进度。
- 试做范围固定显示为"30 天营销计划＋3 张图片"，平台适配不减少这 3 张图片额度。
- 若资料不足，明确列出缺什么，避免访客只看到长期等待状态。

第三步：查看试做结果

- 展示 30 天营销计划和 3 张图片。
- 每张图片下展示适配版本和文案，清晰标明属于同一份内容。
- 提供集中反馈入口，收集风格、内容准确性和修改意见。
- 展示后续付费服务的交付范围和联系入口。

第四步：转入付费合作

- 沿用试做客户资料和已确认风格。
- 确认客户、平台、内容额度、价格和服务周期。
- 预付款到账后进入正式生产。
- 生成可转发给客户的资料与活动提交链接。
- 免费试做内容与付费期额度分开记录，不在转付费时重复扣费。

完成标准：从提交到收到样片，再到预付费合作，资料和客户归属能够连续保留，无需反复填写。

五、实施顺序

| 阶段 | 交付结果 |
|---|---|
| 第 1 阶段：业务规则与素材 | 交付范围表、图片计数规则、试做规则、样板门店资料和样片 |
| 第 2 阶段：提交与试做 | 可用的试做表单、专属查看链接、计划和图片结果页、反馈入口 |
| 第 3 阶段：流程演示 | 与真实试做页面一致的完整演示、客户提交示例、代理商汇总和月报样本 |
| 第 4 阶段：合作介绍页 | 完整文案、样例展示、流程入口、试做入口和分享封面 |
| 第 5 阶段：上线核对 | 提交可回访、客户归属正确、预付费状态准确、同图适配不重复扣额度 |

上线前需要最终确定的业务参数：试做名额范围、试做交付时间、各档产量和平台数、修改规则、视频计数方式，以及平台费用具体包含哪些执行工作。

## 二、Claude 的初步评审（供参照，非用户原话）

针对上述计划，评审时指出以下问题：
1. "适配"与"生成新图"边界未定义，是额度争议最大来源。
2. 视频先在页面承诺交付，计费/计数规则却未定。
3. 平台费具体包含的执行范围未定，但"计费说明"页面已经要上线展示。
4. 试做名额的适用范围（按代理商限1次 vs 按客户限1次）与四节试做流程设计存在潜在冲突。
5. 二、三节都要求制作一套完整虚构样板门店资料，未说明是否共用。
6. 代理商-客户账号/数据模型在现有系统（一人一工作室）里没有技术落点。
7. 续费流程未定义。
8. 退款/剩余额度处理未覆盖。
9. 计费说明没有价格锚点，可能拖慢试做转化。
10. 首屏真实样例与流程演示样例是两套不同数据，叙事割裂。
11. 合作介绍页依赖 2、3 阶段 UI 定稿后的真实截图，UI 迭代会导致截图过期。

## 三、用户对评审的澄清与决定（原话，2026-10-18）

1. "这种不算新图,但只能改 2 次,再修改就算新图"
2. "视频每个月只能生成 2 个 12 秒的视频,多余 2 个要单独收费,超过时长的也要单独收费"
3. "平台费这条需要再讨论,现在不知道你说的是什么意思"
4. "需要限制每个客户限制试做一次,不用限制代理商,因为代理商可能去谈很多客户,代理商需要发样品去签合同的"
5. "二,三节共用一套样本门店数据集"
6. "你就可以想象成代理商"代替"客户创建了一人一个工作室的资料,所以这样不矛盾,还是一个客户一个 ID"
7. "续费这里就是按常规的 saas 模式"
8. "计费逻辑一会再讨论"
9. "首屏真实样例直接复用进流程演示，变成同一个故事的两个入口，而不是两份互不相关的素材。"

## 四、已确定规则（整理版，供后续开发参照）

- **修改规则**：颜色/文字/构图等微调（素材基本不变）不算新图，每份原始内容最多免费改 2 次；第 3 次起算新图，扣新的图片额度。
- **视频额度**：每月 2 个、每个限 12 秒；超出数量或超出时长都单独收费（具体单价未定，待后续补充）。
- **试做名额**：按客户限制 1 次，不按代理商限制——代理商可以为多个不同客户各申请一次试做，用于发样品签约。
- **样板数据**：合作介绍页（二节）与流程演示（三节）共用同一套虚构样板门店数据，不重复生产。
- **代理商-客户账号模型**：不新增独立的"代理商"数据实体层级；每个客户仍然是独立的一人一工作室资料（独立 ID），代理商的角色是"代替客户操作"。—— 遗留技术问题（非本次讨论范围，留给后续技术方案）：代理商账号本身如何获得合法访问/切换多个客户工作室的权限，这是访问控制问题，数据归属已经定了。
- **续费**：按常规 SaaS 周期自动续费模式处理。
- **首屏/流程演示素材**：共用同一套真实样例，作为同一个故事的两个入口，不用两套互不相关的素材。
