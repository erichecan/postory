# Same photo and copy: fixed template vs AI concepts

The comparison uses the Autumn Cat-Eye template's sample photo, `hero-autumn-cat-eye-sample.png`, and its existing copy:

- Headline: `秋日猫眼 新品上线`
- Subtitle: `一抹流光，点亮秋日`

The fixed-template reference is the shared-renderer 4:5 preview. The three AI concepts were generated with the built-in ImageGen tool from the same source photo and copy:

1. `ai-editorial-option-01.png` — expressive beauty-editorial typography and botanical detail.
2. `ai-luxe-option-02.png` — champagne paper, copper foil and restrained luxury campaign styling.
3. `ai-bold-option-03.png` — high-contrast plum and orange social-feed composition.

`same-photo-copy-comparison.jpg` is a contact sheet for visual comparison. These are concept outputs, not production-ready exports: image generation slightly redraws details of the source photo and embeds text into a flattened image. This fixture has no appointment copy set, so appointment text is intentionally absent from all four versions.
