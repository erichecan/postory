## 产品闭环与边界

作品照片 → 制作笔记 → 导出并由用户手动发布 → 美甲师手动录入预约 → 空档变化 → 更新草稿/再次创作。

没有预约数据也能制作笔记，添加档期是可选项；AI 失败时仍能手动编辑并导出。第一版不做社交平台自动发布、自动读私信、复杂图片重绘/视频、完整营销分析，以及 Membership / Gift Card / Points / POS 的 Solo 集成。

## 各包任务与验收标准

### 1. 项目基础与账号 · P0

- 移动优先路由、共享品牌/UI、Create / Appointments / Me 导航。
- 共享注册登录和持久化会话、退出、受保护路由、安全返回路径。
- 工作室名称与时区设置、幂等创建、账号隔离、独立只读 Demo。
- 验收：新用户进入自己的工作室；刷新/重新登录后资料保留；重复设置不创建重复工作室；不同账号不能互读/互改；原平台流程保持可用。

### 2. 作品素材库 · P0 · 本地已实现

- 手机相册一次选择 1–5 张照片，验证格式、数量和大小。
- 照片压缩、真实上传、存储和持久化素材记录；记录归属与上传状态。
- 展示处理中、成功、失败、重试等反馈；失败不能产生看似可用的素材。
- 删除素材、调整所选图片顺序，从已有素材库再次选择。
- 验收：登录后的 `/nails/create` 可实际上传；刷新和重新登录仍可查看；同一素材可再次选择而无需重新上传；删除状态一致；另一账号或未登录请求无法读取、删除或更改素材。上传失败/超限有明确反馈，手机布局可用。
- 本包不要求提前完成 Post 编辑器；须提供能实际选择和复用素材的流程，并为后续 Post Media 独立排序保留正确的数据关系。

### 3. 预约本与空档引擎 · P0

- 设置营业日、营业时间、默认预约时长。
- Today / Week 日期切换；添加、编辑、取消预约。
- 自动计算空档、防止冲突、手动关闭时间段。
- 所有时间绑定工作室时区，覆盖跨天与夏令时边界。
- 验收：新建预约后相关时间立即从可用空档中消失；编辑/取消后空档正确恢复；冲突预约不能并发写入；不同工作室相互隔离。

### 4. Create Post 内容编辑 · P0

- 从素材库选择照片，选择晒作品、填空档、促销、日常等主题。
- 可选加入档期及具体时间，编辑标题、正文与标签。
- 草稿持久化并能重新打开，每篇笔记保存自己的图片选择和顺序。
- 验收：不调用 AI、没有预约数据时，也能完成并保存一篇笔记。

### 5. AI 文案生成 · P0

- 输入平台、主题、作品描述、服务、档期、语气。
- 生成标题、正文和标签，支持重新生成及手动修改。
- 调用限额、错误记录和失败反馈，不虚构价格、优惠或可用档期。
- 验收：生成可编辑的中文小红书笔记；失败时手动创作仍可继续。

### 6. 图片模板与导出 · P0

- 作品优先、档期优先、活动优先三套模板。
- 照片裁切、标题/档期排版、适合小红书的竖版输出。
- 导出 PNG/JPEG，复制文案，手机保存或系统分享。
- 验收：图片清晰、中文正常显示；在手机上实际保存成功，文案可复制。

### 7. 预约与营销数据联动 · P0

- 草稿关联选中空档，并保存内容生成时的时间快照。
- 预约变化后标记受影响草稿可能过期。
- 读取最新档期、更新内容并重新生成图片。
- 验收：预约变化可触发正确草稿提示；明确已导出图片不会自动变化，旧档期不会被误呈现为实时可用。

### 8. 发布记录与内容复用 · P1

- 草稿、已导出、已发布（用户手动确认）状态。
- 保存历史笔记与图片；复制旧笔记，新内容可快速替换照片和档期。
- 验收：下一次创作可复用旧内容，修改副本不影响原笔记；复制后的旧档期须重新验证。

### 9. 测试、部署与真实交付 · P0

- 手机浏览器与相册权限、跨账号隔离及上传检查。
- 时区、跨天、预约冲突；AI/上传失败和断网后的恢复。
- HTTPS、日志、备份、基础隐私说明。
- 使用真实手机完成创作、导出、预约、再次创作的端到端流程。
- 验收：真实用户可独立完成整个闭环。记录真实邮件投递、存储、部署和恢复验证，不能仅凭本地 Demo 宣称上线完成。

## 依赖与接力

实施顺序：1 → 2 → 3 → 4 → 5 → 6 → 7 → 9；8 是首版稳定后的扩展。测试随每包执行，9 负责完整交付验收。

后续数据对象：Service、Appointment、Availability、Media Asset、Post、Post Media、Post Availability、Template。除现有 User/Studio 与可复用主平台对象外，不能假设这些模型已经存在；实施时检查 schema。Post Availability 须保存时间数据与生成时快照，不能只保存描述文字。

切换开发工具前后都使用 [CONTINUE.md](./CONTINUE.md) 作为入口。完成任一包后更新本表和 HANDOFF，记录实际验证结果。
