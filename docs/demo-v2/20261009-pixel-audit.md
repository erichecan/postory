- 寿司 8 张稿目前压缩为 7 个路由，调整内容和最终成品导出需要独立页面或明确的独立状态。
- 美甲上传页原稿标题居中，照片格为横向长方形；当前标题左对齐且照片格为正方形。
- 首页原稿功能区为四列，当前为两列；社媒预览原稿为不同尺寸、错位和旋转的卡片，当前为等宽水平滚动的简化卡片。
- 色彩、Logo、手写行业字、装饰纹理、图片拼贴、平台图标、步骤样式均未完成视觉匹配，emoji 不能作为最终图标验收。
- 模板展示目前仍有禁用占位，不能计作完成设计稿里的六款模板。
- 旧台账中的类型检查、导出成功、无横向溢出是功能证据，不是像素一致证据；旧页面标注仍为“定性状态待确认”。

## 下一轮验收方式

1. 以原稿测量布局，明确 CSS 视口与原图像素的映射；手机系统状态栏及 Home Indicator 独立于网页内容。
2. 使用原稿同款照片及相同内容建立可重复的视觉状态，上传页面复现 4/6 张，避免用不同照片或空状态比较。
3. 按整体布局、照片与模板、字体、间距、控件、装饰逐页修正。
4. 生成原图、实际页面截图、透明叠加、差异图，并记录每页剩余差异；浏览器字体抗锯齿与 AI 图片中文字的差异如实列出。
5. 同时验证上传、编辑、草稿、导出、导航和移动边界，不能用整页原稿图片充当实现。
